# Shivarathri Karthik — AI/ML & Agentic AI Portfolio

A recruiter-focused Streamlit portfolio for **Shivarathri Karthik**, showcasing enterprise experience across Machine Learning, Data Science, Generative AI, RAG, LLMs, Agentic AI, MLOps and cloud-native AI engineering.

## UI structure

- Recruiter-first hero section with profile photo
- Clean snapshot metrics
- AI/ML, GenAI and Agentic AI expertise
- Detailed client experience timeline
- Engineering capabilities
- Technology stack
- Education and certifications
- Clear recruiter contact CTA
- Minimal footer

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

Keep `Passport Photo Karthik.jpg` in the same directory as `app.py`.

## Deploy

Ready for Streamlit Community Cloud. Use `app.py` as the main file.
